# Changelog

## Assignment 12 — Service Layer & REST API

### Added
- **Service Layer**
  - `SensorReadingService` — handles sensor reading creation with validation (temperature, humidity, water flow ranges)
  - `ConfigurationService` — manages simulator configuration with validation (update frequency 1–60s)
  - `SimulationLogService` — manages simulation lifecycle (start, end, status tracking)

- **REST API** (FastAPI)
  - `GET/POST /api/readings` — list and create sensor readings
  - `GET /api/readings/{reading_id}` — get reading by ID
  - `DELETE /api/readings/{reading_id}` — delete a reading
  - `GET /api/readings/anomalies` — get anomalous readings
  - `GET/PUT /api/config` — get and update simulator configuration
  - `POST /api/simulations/{log_id}/start` — start a simulation
  - `POST /api/simulations/{log_id}/end` — end a simulation
  - `GET /api/simulations` — list all simulations
  - `GET /api/simulations/{log_id}` — get simulation by ID

- **Tests**
  - Unit tests for all three services (`tests/test_services.py`)
  - Integration tests for all API endpoints (`tests/test_api.py`)
  - 21/21 tests passing

- **Documentation**
  - OpenAPI/Swagger UI auto-generated by FastAPI at `/docs`
  - Screenshot saved in `/docs/swagger-ui.png`
